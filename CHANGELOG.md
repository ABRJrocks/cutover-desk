# Changelog

## 0.1.0

Initial public release.

- Dependency-aware plan editor with cycle validation, critical path and owner-overlap warnings.
- Sequence, timeline, activity and rollback review surfaces.
- Human-operated rehearsals with evidence notes and explicit pause/resume/abort decisions.
- Replay-validated JSON imports and workspace, plan and Markdown exports.
- Local persistence, corrupt-data recovery and stale-tab protection.
- Core tests, Chromium workflow tests, automated accessibility checks and static Pages deployment.

Early release: single coordinator, one active browser tab, no production command execution, authenticated approvals, tamper evidence or team synchronization.
